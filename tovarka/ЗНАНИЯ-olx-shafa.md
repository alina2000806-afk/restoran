Источник данных: уведомления OLX (403 письма за год) и Shafa (530 с 2019) в почте Алины. Сайты olx.ua / shafa.ua / temu.com из облака закрыты сетевой политикой.

## Факты по OLX
- ≈150 объявлений за 2 года, 42 продажи через OLX Доставку (≈35 реальных, остальное — отмены и повторные покупки).
- Продавалось только б/у с названием: телефоны Samsung, колонки, ноутбук, системный блок, принтер, роутер, микроволновка; зоотовары (6); картины по номерам ×3, термосы, маслопресс; милитари (подсумки, плитоноска).
- Не продалось ни разу: камин-увлажнитель (3 размещения), павербанки (3), худи для собак (4), очки Ray-Ban (3), маркеры, фартук, спички. Щур на продажу за 1 300 ₴ и акула (с 01.09) — продаж через OLX Доставку нет.
- Прокат: объявление «оренда костюм криски» 01.09 → запросы на бронь через календарь OLX 05.09, 11.09, 15.09. Мыши ×5 рекламировались 15.10, второе объявление OLX пометил близнецом 16.10 — держать одно на персонажа.
- Паук переразмещался каждые 30 дней с 10.2025 (лимиты рубрик), запросов на бронь через OLX по тесным костюмам нет.

## Факты по Shafa
- Продажи только в 2020–2021 (краска для бровей Igora, корсет, расчёска). С 2023 — только покупки.
- Тарифы с 31.12.2025: 20 % до 500 ₴ (мин. 30 ₴), 17 % на 501–1 000 ₴; покупатель платит 1,5 % + 7 ₴. Для костюмов не подходит.

## Рынок проката надувных костюмов (OLX)
- 300–500 ₴/сутки по Украине; Харьков 200–400; Днепр T-Rex 490. Наши 250 ₴ — самые дешёвые, это и даёт брони.
- Конкуренты держат 6–12 персонажей: мышь/крыса, динозавр, жаба, акула, единорог, корова, пчёлка, белка, зебра, жираф, медведь, клоун, енот, инопланетянин; к Новому году — Гринч, снеговик, пряник.
- Аниматор/ростовая кукла 900–3 500 ₴ за выход — наш аргумент «в 5 раз дешевле».
