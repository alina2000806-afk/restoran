# Стікери костюмів «Облік» — єдиний стиль

Усі стікери малюються з цих SVG одним генератором, щоб стиль був однаковий:
мультяшна дитина в костюмі на весь зріст, велике обличчя (шкіра `#ffd2b0`, карі очі з бліком, рум'янець),
об'ємні кольори через радіальний градієнт (світло зліва-згори), темна обводка 3 px у тон кольору,
відблиск на голові, біла обводка-стікер ~8 px, PNG 500×500 з прозорим фоном, фігура ~430 px по центру.
Надувні костюми — капюшон з отвором для обличчя (функція `inflatable`), облягаючі — `suit_kid`.

Новий костюм: додай його в `gen.py` (або окремий SVG у тому ж стилі), потім
`python3 gen.py && node render.js && python3 finish.py` і скопіюй `out_<назва>.png` у `orenda/media/st/`.
Не змішувати з 3D-рендерами з нейромереж.
